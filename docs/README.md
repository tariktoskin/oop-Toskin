## Сдача

**Лабы 1 и 2 (сам):**

1. На странице этого репозитория **Use this template → Create a new repository**, имя `oop-фамилия`, Public. Ссылку в таблицу группы.
2. Для каждой лабы своя ветка (`lab1`, `lab2`) и папка (`lab1-todo/`, `lab2-paint/`).
3. До срока открыть Pull Request из ветки лабы в `main`.

**Лабы 3, 4 и РПГ (в паре, в команде):**

1. Один создаёт репозиторий, остальных добавляет в **Settings → Collaborators**.
2. Каждый коммитит со своего аккаунта.
3. До срока открыть Pull Request в `main`.

**В папке лабы `README.md`:** автор (авторы), как запустить, скриншот, отмеченный чек-лист, коротко как устроен проект: какие классы, кто от кого наследуется, что использовали. В паре и команде: кто что делал.

**Коммиты:** коммит после каждого законченного шага, сообщение говорит, что сделано («Добавлено удаление задачи», а не «upd»). Папки сборки (`bin/`, `obj/`, `build/`, `.idea/`, `.vs/`) не коммитить, они уже в `.gitignore`.
