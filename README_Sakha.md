## 1) Саҕалааһын

1. `StudentChat.sln` билэни Visual Studio Community-га арый.
2. Проегы хомуйан, `Ctrl + F5` көмөтүнэн саҕалаа.
3. Бастакы көмпүүтэргэ «Запустить сервер» баттааһынын баттаа.
4. Сервер IP-адреһын, `5000` портун уонна нигиҥи киллэр.
5. Атын көмпүүтэрдэргэ приложениены саҕалаан, сервер IP-адреһынан холбон.

## 3) Чек-лист

1. **Сервер уонна клиент.** Тус-туспа программалар. Адрес уонна порт киирии түннүгэр киллэриллэр. Атын-атын көмпүүтэрдэргэ үлэлиир.
2. **Киирии.** Ник көмөтүнэн киирии, ник туһаныллар буоллаҕына киириини көннөрбөт буолуу, киирии уонна тахсыы туһунан биллэриилэр.
3. **Чат.** Ник, кэм уонна тиэкис көстөр лента. Биллэриини баттааһын эбэтэр `Enter` көмөтүнэн ыытыы; биллэрии барыга тиийэр. Онлайн кыттааччылар тиһиктэрэ саҥардыллан турар.
4. **Класстар уонна протокол.** Таблицаҕа ыйыллыбыт класстар (эбэтэр олорго майгынныыр класстар). Ситим клиенэ түннүктэн тутулуга суох. Протокол `README`-ҕа ойууланар.
5. **Туруктаах үлэ.** Түннүк тоҥон хаалбат. Биир клиент холбонуутун быһан кэбиһии сервер уонна атын клиенттар үлэлэрин тохтотпот. Сервер кыайан холбоммотоҕуна программа сыыһан тахсыбат, оннугар алҕас туһунан биллэрии көрдөрөр.
6. **README.** Хайдах саҕалыырга, скриншот, чек-лист, проектың тутула, протокол уонна ким тугу оҥорбута.

### Эбии сорудахтар

**★ (3 баал).** Туспа биллэриилэр: онлайн тиһиктэн кимҥэ ыытаргын тал. Биллэриини икки эрэ киһи көрөр, лентаҕа ол туспа өнүнэн көрдөрүллэр.

**★★ (3 баал).** История: сервер биллэриилэри билэҕэ бигэргэтэр уонна саҥа клиентка бүтэһик 20 биллэриини ыытар. Сервер хос саҕаланнын кэннэ эмиэ история хаалар.

## 4) Проект тутула

- **Models** — `ChatMessage` уонна `ChatLine` класстар, биллэриилэр дааннайдарын харайыы.
- **Networking** — `ChatServer`, `ClientHandler`, `ChatClient`, ситим нөҥүө дааннайдары атастаһыы.
- **Views** — киирии уонна чат түннүктэрэ, WPF-интерфейс.

## 5) Протокол

Биллэриилэр TCP нөҥүө JSON форматынан ыытыллаллар: биир биллэрии — биир устуруока.
